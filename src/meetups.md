# Meetups

- Attendance is free!
- Feel free to bring any games you want to play.
- We try to be very welcoming of new players, but sometimes everyone is already in a game, and you'll have to wait until something ends or other players show up.
- If you're feeling anxiety about coming to a meetup just know that you're certainly not alone.

- Well Played generously allows meetup attendees to use there game library for free. You do not need a pass.
- We are almost always in the "cafe portion" (turn left when you walk in).
- There should be a roll of name tags on a table. Please make and wear a name tag. It helps everyone.
- We have a dedicated spot for games that belong to the club members that is separate from the Well Played library, and an area reserved for us to mingle and play near each other.
- Official start time is 5:30pm but there is usually someone there by 5.
